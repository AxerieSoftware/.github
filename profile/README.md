# Axerie

Small, well-made apps and free, open-source tools that add what the software you already use doesn't do yet.

| Tool | What it does |
| --- | --- |
| [**Wingspan**](https://wingspan.axerie.com) | Browser extension for Monarch Money: see when every bill is due, which card payments checking can cover, and how much is safe to spend today. |
| [**.NET Config Wizard**](https://dotnetconfig.axerie.com) | Picks the analyzers, code style and build settings for a .NET repo, then writes the `.editorconfig`, props and `global.json` for you. Runs in your browser. |
| [**studentloans-mcp**](https://github.com/AxerieSoftware/studentloans-mcp) | MCP server that lets an AI agent check your federal student loan balances on studentaid.gov. |
